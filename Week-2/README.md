# Assignments Structure

## Array Methods Assignments

### Assignment 1 – Daily Temperature Analyzer

Used array methods like `filter()`, `map()`, `reduce()`, `find()`, and `findIndex()` to analyze and transform temperature data.

### Assignment 2 – Online Course Name Processor

Processed course names using array methods and generated formatted output strings.

### Assignment 3 – Student Marks List

Implemented pass filtering, grace marks addition, highest mark calculation, and searching operations on student marks.

### Assignment 4 – Shopping Cart Summary

Built an e-commerce cart processing system to calculate total prices and identify available products.

### Assignment 5 – Student Performance Dashboard

Created a student grading system by processing arrays of objects and calculating average marks.

### Assignment 6 – Employee Payroll Processor

Processed employee salary data and calculated net salary with bonus additions.

### Assignment 7 – Movie Streaming Platform

Implemented movie filtering, rating analysis, and searching operations for recommendation-based data.

### Assignment 8 – Bank Transaction Analyzer

Analyzed banking transactions by calculating account balance and processing credit/debit operations.
