# Assignments Structure

## Day 1 Assignments

### Assignment 1 – Biggest Among Two Numbers

Created a program to compare two numbers using conditional statements and display the greater number.

### Assignment 2 – Biggest Among Three Numbers

Implemented nested conditional logic to find the largest among three numbers.

### Assignment 3 – Sum of Array Elements

Used loops to calculate the total sum of all elements present in an array.

### Assignment 4 – Smallest Number in an Array

Developed a program to identify the smallest value from an array using iteration.

### Assignment 5 – Biggest Number Using Function

Created a reusable function to determine the largest among three numbers.

### Assignment 6 – Sum of Array Using Function

Implemented a function that accepts an array as input and returns the sum of its elements.

### Assignment 7 – Searching Key Element in Array

Built a simple search functionality to check whether a key element exists in an array.


## Day 2 Assignment

### Employee Array Manipulation

Worked with an array of employee objects and performed operations such as:

* Inserting a new employee
* Removing an employee
* Updating employee marks

Used JavaScript array methods like `splice()` and loops for dynamic data manipulation.
